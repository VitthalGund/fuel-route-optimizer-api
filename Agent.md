# Fuel Route Optimizer API — Agent Context

## Application Building Context

Read the following files in order before implementing
or making any architectural decision:

1. `context/project-overview.md` — product definition,
   goals, features, requirements, and scope
2. `context/architecture.md` — system structure, tech stack,
   database schema, external APIs, and request flow
3. `context/data-context.md` — CSV analysis, data pipeline,
   geocoding strategy, and station data model
4. `context/api-contract.md` — endpoint spec, request/response
   schemas, error handling, and caching rules
5. `context/code-standards.md` — project structure, implementation
   rules, naming conventions, and dependency list
6. `context/ai-workflow-rules.md` — development workflow,
   scoping rules, testing approach, and delivery order
7. `context/progress-tracker.md` — current phase,
   completed work, open questions, and next steps

Update `context/progress-tracker.md` after each
meaningful implementation change.

If implementation changes the architecture, scope, or
standards documented in the context files, update the
relevant file before continuing.
